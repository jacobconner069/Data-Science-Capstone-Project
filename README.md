Data Science Capstone Project

This repository contains files as a part of the project for the IBM Apllied Data Science Capstone course through Coursera
DS-Capstone-Presentation.pdf is the final slideshow presentation for the project
Das-App.py is a python script using Dash to create a dashboard application displaying both interactive pie charts and scatter plots used to explore the dataset
Data-Collection.ipynb uses Jupyter Notebooks to collect the data used for the project and sperate it into datasets and tables.
