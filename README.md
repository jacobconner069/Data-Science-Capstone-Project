Data Science Capstone Project

This repository contains files as a part of the project for the IBM Apllied Data Science Capstone course through Coursera.
The project aims to use the data science process to predict future spacecraft landing outcomes based on previous data provided in the dataset. EDA is used to uncover relationships between data points, and data visualization is used to demonstrate these simmilarities in an understandable format.

DS-Capstone-Presentation.pdf is the final slideshow presentation for the project.
Das-App.py is a python script using Dash to create a dashboard application displaying both interactive pie charts and scatter plots used to explore the dataset.
Data-Collection.ipynb uses Jupyter Notebooks to collect the data used for the project and sperate it into datasets and tables. 
Data-Visualization.ipynb creates various charts and graphs used to visualize and explore the data.
Data-Wrangling.ipynb explores the data for patterns.
First-Stage-Landing-Prediction.ipynb uses various machine learning techniques to try and predict the outcome of launches based on the data. These machine learning models were compared to determine the most effective model making the most accurate predictions.
Folium-Visuals.ipynb uses the folium library to create geographical maps and charts displaying the launch data from the dataset.
SQL-EDA.ipynb uses SQL programming to perform EDA on the dataset and discover any patterns that lie within it.
Webscraping.ipynb performs webscraping to gather data to be used to help draw conclusions in the project.
